# Employee Attendance Analysis - SQL Project

## Project Overview

This project analyzes employee attendance data using PostgreSQL.

The project covers employee details, departments, attendance status,
attendance percentage, department-wise attendance, daily attendance,
attendance ranking, and a final management attendance report.

## Database Tables

- Departments
- Employees
- Attendance

## Key SQL Concepts Used

- SELECT
- WHERE
- JOIN
- LEFT JOIN
- GROUP BY
- HAVING
- CASE WHEN
- SUM
- COUNT
- ROUND
- RANK() OVER()
- ORDER BY
- LIMIT
- Foreign Keys

## Analysis Performed

1. Total number of employees
2. Department-wise employee count
3. Employee-wise attendance status
4. Employee attendance percentage
5. Employees with attendance below 80%
6. Most absent employees
7. Department-wise attendance percentage
8. Daily attendance summary
9. Employee attendance ranking
10. Final management attendance report
11. Employee of the Month

## Employee of the Month

The project identifies the top-performing employee based on:

- Highest attendance percentage
- Lowest late days
- Lowest absent days

## Tools Used

- PostgreSQL
- SQL
- pgAdmin

## Project Objective

The objective of this project is to demonstrate practical SQL skills
by analyzing employee attendance data and generating meaningful
business insights for management.
